# Общие элементы Altenar

Обе страницы собирает Vite: `index.html` открывает Home, `Sportsbook/index.html` — Turnkey. Turnkey сохраняет экспортированную разметку и загружает общие модули через `src/shared/sportsbook.ts` до запуска исходного бандла. Уникальные блоки, тексты и обработчики остаются в страницах.

| Элемент | Источник и общий файл | Подключение |
| --- | --- | --- |
| Типографика | Turnkey, `src/shared/typography.css` | Обе страницы. Свойства `--ui-type-*` и роли `data-ui-type` для новых элементов. Цвет и ручные переносы остаются в разметке. |
| Меню | Turnkey, `navigation.ts` и `navigation.css` | Обе страницы. `mountNavigation()` принимает существующие пункты страницы через её разметку; управляет раскрытием Solutions и переходом на Home по логотипу. |
| Кнопка со скосом | Home, `split-button.ts` и `controls.css` | Обе страницы. `mountSplitButtons(scope)` оформляет узлы с `data-premium-split`; ссылка, действие и состояние disabled задаются страницей. `data-split-variant="light"` сохраняет светлый вариант Home hero. |
| Стрелки | Home, `arrows.ts` и `controls.css` | Карусели Home. `mountArrow` задаёт направление и оформление; `mountArrowRollover` подключает анимацию к существующему действию. На Turnkey в Tools используется отдельная пагинация по шагам. |
| Глобус | Turnkey, `public/shared/globe.js` и `globe.css` | `data-ui-globe` отмечает контейнер на каждой странице. `mountGlobe(host, options)` использует общий рендерер Mappo. Поиск и выбор страны принадлежат Home. |
| FAQ | Home, `faq.ts` и `faq.css` | Обе страницы передают свои `question`, `answer` и начальное `state` в общий компонент. У каждой страницы свой экземпляр React. |
| Контактный блок | Home, `contact.ts` и `contact.css` | Обе страницы используют `createContactSection(React)`: общий заголовок, текст, группы выбора и разметка `Next step`. Кнопка использует общий `mountSplitButtons` для цветов, контура и движения стрелки. Без обработчика `onNext` кнопка отключена, как в текущем прототипе. |
| Подвал | `footer.ts` и `footer.css` | Обе страницы передают свою разметку ссылок и юридического текста; общий модуль оформляет поток страницы, фон и ряд логотипов. |

Для нового раздела используйте существующие роли и подключайте нужный модуль в точке входа страницы. В Turnkey меняйте только адаптеры в активном бандле и правки в подключённых к нему CSS и JS, если изменение нельзя сделать в общей части.
